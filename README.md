# SlideChat

PDFを、チャットでAIが生成しているように1枚ずつ表示するReact製プレゼンテーションアプリ。生成AIスライドへの風刺をテーマにした、静的サイトです。

## 起動

Node.js 22.13以上（または24以上）を推奨します。

```sh
npm install
npm run dev
```

画面でPDFを選択し、最初のメッセージを編集して送信します。PDFなしでは4枚のデモが動きます。発表中は「次のスライド」、Space、右矢印で進めます。生成演出は1秒固定です。自動送りでは追加の待ち時間なしで、1秒ごとに次のスライドを表示します（PDFの描画時間は別途かかります）。全画面ボタンでブラウザの全画面表示へ切り替えます。

「新しいプレゼン」または「最初からやり直す」で表示をリセットします。PDFはそのまま残り、開始前に差し替えできます。ページを再読み込みするとPDFは失われます。

## 静的サイトとして公開

```sh
npm run build
```

生成された `dist/` 全体を静的ホスティングへ配置してください。相対パスのためサブディレクトリでも動作します。サーバー処理・APIキー・実際のAI生成は不要です。PDF.jsのWorker、日本語CMap、標準フォント、画像デコーダーも同梱し、CDNには依存しません。

PDFはブラウザ内で処理し、外部へ送信しません。最大500MB、パスワード付きPDFは解除後に読み込んでください。PDFの内容は画像として表示されます。表示済みページのcanvasを保持するため、非常に長い資料ではメモリ使用量が増えます。

## 検証

```sh
npx playwright install chromium
npm test
```

デモの手動・自動送り、リセット、PDF読込と描画、不正なPDF、モバイル表示を確認します。対応対象は最近のChrome・Edge・Firefox・Safariです（実行済みの自動検証はChromium）。

PDF表示は [Mozilla PDF.js](https://mozilla.github.io/pdf.js/) を使用しています。
